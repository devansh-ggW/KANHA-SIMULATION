About the project

Ancient imagery. Real equations.

Why Kanha?

KANHA SIMULATION uses familiar Krishna-inspired motifs as the visual language for science. The stories are the framing; the mathematics underneath stays grounded in real physical relationships.

Why lightweight?

The app avoids a full 3D engine, heavy particle fields and permanent render loops. Most of the visual depth comes from simple Canvas geometry, perspective cues and controlled lighting.

What runs locally?

Simulation math, animation and interaction happen in the browser. No account, database or physics API is needed. The site can be deployed as a static GitHub Pages project.

Built for the classroom

The design targets large displays and older integrated graphics. A dedicated performance switch lets the visual layer step down while leaving the core physics and controls intact.
